Política de privacidade

Última atualização: 22 de outubro de 2026.

Quais dados o app usa

  • Conta Google: nome, e-mail e foto de perfil, apenas para mostrar qual conta está conectada.
  • Seu catálogo: os itens e registros que você cria (nome, descrição e fotos).

Onde os dados ficam

Os dados são salvos somente na pasta Catálogo do Google Drive da sua própria conta. Uma cópia também fica no seu aparelho, para o app funcionar sem internet. O app não tem servidor e não envia seus dados para nenhum outro lugar.

Acesso ao Google Drive

O app usa a permissão drive.file. Com ela, ele só acessa os arquivos que ele mesmo criou. Ele não lê, não altera e não apaga os outros arquivos do seu Drive.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Compartilhamento

Seus dados não são vendidos, compartilhados nem usados para publicidade.

Como apagar seus dados

  • Apague a pasta Catálogo do seu Google Drive.
  • Desinstale o app para apagar a cópia do aparelho.
  • Para retirar a permissão do app, acesse myaccount.google.com/connections.
